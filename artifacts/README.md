# Agent Artifacts

This folder contains outputs from the Copilot Orchestrator agents.

## Structure

| Folder | Purpose |
|--------|---------|
| `plans/` | Implementation plans and phase completions |
| `reviews/` | Code review verdicts and findings |
| `research/` | Research briefs, citations, and analysis |
| `decisions/` | Architectural Decision Records (permanent) |
| `sessions/` | Session state for resume/continuity |
| `tests/` | Test reports and coverage analysis |
| `specs/` | Project specifications |
| `memory/` | Active context and session memory |
| `.archive/` | Rolled-off artifacts past 30-day TTL |

## Retention

Decisions are permanent. Everything else: 30-day TTL or manual cleanup.

## Naming Conventions

- **Plans**: `plans/{feature-slug}/plan.md`
- **Phase Records**: `plans/{feature-slug}/phase-N-complete.md`
- **Reviews**: `reviews/{YYYY-MM-DD}-{feature-slug}.md`
- **Research**: `research/{topic-slug}.md`
- **Sessions**: `sessions/{session-id}.json`
- **Decisions**: `decisions/DEC-{NNN}-{slug}.md`
- **Active Context**: `memory/activeContext.md`
